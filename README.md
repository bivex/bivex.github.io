# bivex.github.io

Personal website and portfolio showcasing projects, skills, and professional experience.

## Built With

- HTML5 / CSS3
- Monokai syntax theme
- Static site generation

## Structure

```
├── index.html          # Homepage
├── blog/               # Blog section
├── articles/           # Articles archive
├── tags/               # Tag pages
├── archive/            # Archive
├── style.css           # Main stylesheet
├── monokai.css         # Code highlighting theme
└── assets/             # Static assets
```

## Local Development

```bash
# Serve locally with any static file server
python3 -m http.server 8000
# or
npx serve .
```
